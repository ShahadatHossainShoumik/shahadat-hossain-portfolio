INTI Vending MachineDigital Touchscreen UI Redesign

An eight-screen Figma touchscreen interface that replaces INTI’s button-based vending machine with a modern, user-tested digital ordering flow.

View on GitHub All Academic Projects

Project Module

Eight-screen digital touchscreen interface for a self-service vending machine.

Technologies & Methods

Figma prototype Google Forms survey Closed-ended questions Likert-scale questions Open-ended question Nielsen’s usability heuristics

Final Outcome

Designed an eight-screen prototype covering browsing to order confirmation. In a survey of 43 students, 83.7% agreed that a digital interface would improve the experience.

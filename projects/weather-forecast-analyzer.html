Weather Forecast AnalyzerBangladesh Weather Data System

A Python data system that turned 350,880 hourly weather observations into 14,620 clean daily city records, with a Tkinter GUI and automatic weather advisories.

View on GitHub All Academic Projects

Project Module

Python application for cleaning, managing, and analysing weather records for Dhaka, Chittagong, Sylhet, and Rajshahi.

Technologies & Methods

Python Pandas NumPy Tkinter Data cleaning Record management (add, search, update, delete) Statistical analysis Rule-based weather advisories Exception & file handling

Final Outcome

Cleaned 350,880 hourly observations (2016–2026) into 14,620 daily city records, with a menu-driven console interface, a Tkinter interface, NumPy statistics, and automatic Normal, Heavy Rain, Heat Alert, and High Wind advisories.
